3. Computational Reproducibility Protocol

        100% Deterministic
      

      

        The Stage 2 analytical pipeline is built entirely in Pure Python using Python standard libraries (csv, json, math, unittest). No external machine learning models or black-box dependencies are required to execute or reproduce findings.
      


      

        

          # Terminal Pipeline Execution Protocol
          
        

        
# 1. Validate raw evidence records and generate schema quality audit
python3 analysis/validate_data.py

# 2. Build network graph topology and map connected components
python3 analysis/build_network.py

# 3. Calculate structural graph measures (degree, betweenness, closeness, density)
python3 analysis/calculate_metrics.py

# 4. Trace multi-hop standardisation pathways and detect cut vertices
python3 analysis/analyse_pathways.py

# 5. Run full test suite to verify mathematical and topological integrity
python3 tests/test_validation.py
python3 tests/test_network.py

      


      

        

          

            1. Data Ingestion & Sanitization
          

          

            Validates data/raw/evidence_records.csv against RFC 4180 standards. Evaluates mandatory fields and flags unverified candidate claims into data_quality_audit.json.
          

        


        

          

            2. Adjacency Graph Construction
          

          

            Constructs adjacency matrices for verified-only and full-spectrum topologies in data/processed/network_graph.json. Performs BFS search to map isolated components.
          

        


        

          

            3. Brandes Betweenness & Articulation
          

          

            Executes Brandes betweenness centrality and Tarjan-based articulation point analysis to isolate single points of failure bridging open-source and institutional SDOs.
